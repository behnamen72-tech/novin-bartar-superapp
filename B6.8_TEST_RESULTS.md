## BFF security sweep

A repository-wide sweep of `frontend/app/api/core/**/route.ts` verified:

- every POST/PATCH/PUT/DELETE Core BFF route uses `proxyAuthenticatedRequest()`
- no unsafe Core BFF route bypasses the centralized B6.2 CSRF/origin enforcement
- every dynamic route parameter is passed through `encodeURIComponent()` before backend routing

## Authorization boundary

The frontend intentionally performs only conservative UX filtering. It does not
calculate authoritative privilege dominance. FastAPI B5.6 remains responsible for:

- `access.manage` authorization
- target-user/Person organization relationship validation
- Role ownership and activity
- organization subtree restrictions
- capability-set delegation / anti-privilege-escalation checks
- last-effective-access-manager protection
- transactional row locking and Audit

Document ACL recovery remains deliberately separate from document content access.
