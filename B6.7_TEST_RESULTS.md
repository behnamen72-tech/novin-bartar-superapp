## Security / integration verification

Verified in source and deterministic checks:

- all unsafe `/api/core/**` BFF routes use `proxyAuthenticatedRequest()`
- all dynamic BFF path parameters use `encodeURIComponent()`
- browser JavaScript never receives the backend bearer token
- document download is proxied server-to-server and returned with `Cache-Control: no-store, private`
- frontend permission/scope logic controls affordances only; FastAPI re-authorizes document operations
- B5.4 restrictive ACL behavior is preserved; ACL cannot expand B3 organization access
- archived/expired lifecycle behavior remains consistent with B5
- BFF download buffering remains bounded by the current 50 MiB document limit and is tracked as technical debt
