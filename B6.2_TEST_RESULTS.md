B6.1 baseline had 90 passing backend tests. B6.2 adds authentication-session tests covering:

- password login issues access + opaque refresh credentials
- plaintext refresh credential is not stored in the DB
- refresh rotates the credential
- old refresh credential replay is rejected
- refresh does not extend the absolute session expiry
- logout revokes the refresh session
- repeated logout is idempotent
- expired refresh token is rejected
- inactive User refresh is rejected
- invalid refresh errors do not echo secrets
- failed password login creates no refresh session
- access JWTs are unique through `jti`
